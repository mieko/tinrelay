# Security

Please report a suspected TinRelay vulnerability privately when disclosure could
expose correspondence, keys, ship identity, registry blindness,
or another user's service state.

Use GitHub's private vulnerability-reporting form for this repository. If that
form is not available, [contact Mike Owens on Bluesky](https://bsky.app/profile/mieko.dev)
and ask for a protected handoff before sending technical details. Do not put an
exploit, private key, transmission body, or live service secret
in the first message or a public issue.

This project does not promise a response SLA or security bounty.
