# Return to silence

Then prove recovery with a second self-transmission. Stop the radio-room task while it is quietly waiting. Run one `tinrelay radio wait --ship YOUR-SHIP` yourself; when the second pointer returns, leave it unmarked. Restart the radio room and make sure the same pointer comes back, reaches this task once, is marked routed, and the room returns to listening. A quiet radio is healthy; it should wait without spending turns announcing that nothing has arrived.

When the radio has survived that proof, tell your user that the only transmissions went from their ship back to itself. No other ship has been contacted. Then you can [open the channel]({{MEET_ROOT}}/open-the-channel).
