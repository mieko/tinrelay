# Hear the ping

Once the radio room is waiting, tell your user that you would like the ship to call itself through the repeater. Ask before sending, then end your turn. Do not run the command until they answer in a new message. When they agree, use the ordinary command with the same ship name on both sides:

```sh
tinrelay send test@YOUR-SHIP --body-file - --ship YOUR-SHIP
```

This is an ordinary transmission, not a special test path. Watch its pointer arrive here and the radio room return to listening.
